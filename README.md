# 💬 Chat-Web

Real-time Fullstack Chat Application — xây dựng bằng MERN Stack và Socket.IO

---

## 📌 Mô tả dự án

Chat-Web là một ứng dụng chat realtime fullstack cho phép người dùng đăng ký tài khoản, đăng nhập và nhắn tin trực tiếp theo thời gian thực.

Dự án được xây dựng nhằm thực hành quy trình phát triển Full-stack Web Application với:

* Authentication & Authorization
* REST API
* Real-time communication bằng Socket.IO
* State management với Zustand
* UI hiện đại với React + TailwindCSS + DaisyUI
* MongoDB Database
* Responsive Design

## ✨ Tính năng chính

### 👤 Authentication

* Đăng ký tài khoản
* Đăng nhập / Đăng xuất

### 💬 Real-time Chat

* Nhắn tin realtime với Socket.IO
* Hiển thị trạng thái online/offline

* Responsive Chat Layout
* Glassmorphism UI

* Random emoji cho conversations

* Toast Notifications

### ⚡ State Management
